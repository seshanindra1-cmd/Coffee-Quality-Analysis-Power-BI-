# ☕ Coffee Quality Analysis (Power BI)

## 📌 Project Overview
This project analyzes coffee quality ratings based on attributes like variety, altitude, grading month, and origin country.  
A Power BI dashboard was created to explore the impact of these factors on overall quality scores.

## 🔍 Problem Statement
The objective was to identify the key factors that influence coffee quality, helping producers and distributors improve quality control.

## 🛠️ Approach
- Transformed unpivoted dataset into an analyzable format.  
- Built a Power BI dashboard with:
  - Overall score comparisons across attributes.  
  - Country-wise and variety-wise quality distribution.  
  - Trends based on altitude and grading month.  
- Added interactivity for detailed exploration.

## 📊 Key Insights
- Coffee variety and altitude significantly impact quality scores.  
- Certain countries consistently produce higher-rated coffee.  
- Seasonal factors (grading month) showed slight variations in quality.  

## 🧰 Tech Stack
- Power BI  
- Data Modeling (DAX, Measures, Relationships)
