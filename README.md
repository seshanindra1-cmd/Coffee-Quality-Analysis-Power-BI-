# ☕ Coffee Quality Analysis (Power BI)

## 📌 Project Overview  
This project analyzes coffee quality ratings using features like variety, altitude, grading month, and country of origin.  
A Power BI dashboard was built to explore how these attributes influence overall quality scores.

---

## 🔍 Problem Statement  
What are the key factors that influence coffee quality?  
This project aims to help producers and distributors understand how attributes such as variety, altitude, and grading time impact rating scores.

---

## 🛠️ Approach  
1. **Data Cleaning & Transformation**  
   - Cleaned the raw dataset (`df_arabica_clean.csv`)  
   - Reshaped/unpivoted data to a format suitable for BI analysis  

2. **Dashboard Development in Power BI**  
   - Created interactive visuals:
     - Score comparisons across varieties, countries  
     - Quality distribution by altitude  
     - Trends over grading months  
   - Applied filtering and interactivity for deeper exploration  

3. **Data Modeling & DAX Measures**  
   - Built relationships and calculated measures using DAX  
   - Generated KPIs (averages, ranks, variances)  

---

## 📊 Key Insights  
- Variety and altitude significantly influence quality ratings  
- Some countries consistently produce higher-rated coffee beans  
- Slight seasonal trends observed in grading month  
- Outliers and variation within categories highlight opportunities for quality control
